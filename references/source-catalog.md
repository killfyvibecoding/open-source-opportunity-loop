## Source handling rules

1. Prefer the official repository or foundation page for final evidence.
2. Use directories for discovery and taxonomy, not as the final license authority.
3. Store the source URL, repository URL, retrieval date, and confidence in any future index.
4. Deduplicate by canonical repository URL.
5. Keep “open source”, “source available”, “free to use”, and “open model” as separate labels.
