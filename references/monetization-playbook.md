# Monetization Playbook

Use these models to turn a reusable open-source base into a testable business. Do not promise revenue; state the hypothesis and the next experiment.

## Models

| Model | Best fit | What to sell |
|---|---|---|
| Productized service | A clear workflow and reachable business customers | Setup, content, operation, and monthly support |
| Private deployment | Sensitive data, internal knowledge, or compliance needs | Deployment, customization, maintenance, and training |
| SaaS | Repeatable workflow and multi-customer demand | Subscription, seats, usage, and premium integrations |
| Open core | A useful community edition with advanced team needs | Hosted version, SSO, audit, analytics, and support |
| Template or starter kit | Developers or agencies want speed | Paid templates, integrations, and implementation guides |
| Plugin or extension | An established ecosystem has distribution | One-time purchase, subscription, or usage fee |
| API | A capability can be isolated and measured | API calls, volume tiers, and enterprise support |
| Content-led product | The problem is education, research, or workflow knowledge | Membership, reports, courses, consulting, and referrals |

## China-specific checks

When the target market is China, check:

- domestic model and cloud alternatives;
- WeChat or enterprise WeChat workflow;
- local payment and invoice requirements;
- ICP and data-compliance implications;
- private deployment and data residency;
- overseas API availability and cost volatility;
- whether the buyer prefers a service contract over self-serve SaaS.

## Experiment ladder

1. Interview three target users and ask for the current workaround.
2. Build a concierge version using the proposed open-source components.
3. Ask for a paid pilot, not only feedback.
4. Measure time saved, output quality, repeat usage, and support burden.
5. Productize only the repeated part of the workflow.

## Pricing hypotheses

Use ranges only as experiments. Separate:

- one-time setup;
- monthly software fee;
- usage or model cost;
- customization;
- support and renewal.

Never present a price found in a founder story as proof that the user's market will pay the same amount.
