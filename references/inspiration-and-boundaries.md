# Inspiration and License Boundaries

## Why this file exists

The interaction design of this Skill was informed by the public structure of [dontbesilent2025/dbskill](https://github.com/dontbesilent2025/dbskill), especially its single entry point, context-based routing, diagnosis before action, and post-task next-step navigation.

## What was adapted conceptually

- one natural-language entry point;
- route selection from the current conversation;
- a short clarification step before heavy work;
- one next action after each result;
- optional knowledge and decision records;
- feedback-driven continuation instead of a rigid skill chain.

## What was not copied

This repository does not copy dbskill's code, Skill files, original wording, knowledge base, assets, or templates. The existing repository remains under MIT, while dbskill is distributed under its own license and terms. Users who want to install dbskill should obtain it from its original repository and follow its current license notices.

The open-source opportunity workflow, examples, wording, and reference material in this repository are original to this project or linked as external sources.

## Practical rule

When combining this Skill with another Skill, reuse behavior only when the source license and attribution requirements permit it. Otherwise, keep the other Skill as a separate dependency and link to its official repository.
