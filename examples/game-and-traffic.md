# Example: Game and Traffic Loop

## User request

> I want to use an open-source game or interactive project to build a small revenue product.

## Search route

1. Start with `README-Game.md` and the historical collection.
2. Find the original repository and confirm its license, assets, engine, and platform policy.
3. Separate game code from art, music, characters, fonts, and third-party SDKs.
4. Use Product Hunt and Indie Hackers only for launch and monetization patterns.
5. Propose a narrow distribution experiment before a large content build.

## Output requirements

Recommend one of:

- a reskinned or localized game with verified asset rights;
- a game-adjacent tool or editor;
- a community, content, or creator service around an existing game ecosystem.

Do not recommend copying a game's brand, art, levels, or proprietary assets.
