# Example: Content Production System

## User request

> I want an AI system that turns a company's documents into social content and sales materials.

## Decision

Treat this as a workflow product, not as a generic chatbot. Search for document ingestion, structured knowledge, templates, approvals, publishing integrations, and analytics.

## Output requirements

- Separate the knowledge source from generated drafts.
- Preserve citations or source references for claims.
- Add human review before publishing.
- Recommend one channel and one audience for the MVP.
- Compare hosted SaaS and private deployment.
- State model cost and data-handling risks.

## First experiment

Take ten real documents from one customer, produce one week of content, and measure editing time and publishing quality before adding more channels.
