# Contributing

Thanks for helping improve Open Source Opportunity Loop.

## What belongs here

- reliable open-source discovery sources;
- reproducible search and evaluation workflows;
- realistic examples;
- corrections to links, licenses, or project-health guidance;
- improvements that make recommendations more actionable.

## Contribution rules

1. Prefer canonical project or foundation URLs.
2. Explain why a source improves discovery, technical verification, or market validation.
3. Do not copy third-party documentation or code without permission and attribution.
4. Keep claims about current stars, releases, prices, and activity tied to a source and retrieval date.
5. Run `python3 scripts/validate_skill.py` before opening a pull request.

## Pull requests

Keep each pull request focused. Include the user problem, changed files, validation output, and any license considerations.
