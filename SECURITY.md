# Security Policy

## Reporting a vulnerability

Do not publish credentials, private data, or an exploitable security issue in a public issue. Contact the repository maintainer privately through the GitHub profile or repository security contact.

## Scope

Report issues involving included scripts, workflows, unsafe instructions, secret handling, or links that distribute malicious software.

This Skill does not request personal access tokens in chat. Use local authentication such as `gh auth login` or a protected environment variable.
